DOCK CO-OP - Windows review build

Extract the whole archive. Keep the executable, data directory and DLLs together.

Local test on one PC:
1. Run Host-Local.cmd.
2. Run Client-1-Local.cmd (and optionally Client-2-Local.cmd).
3. On the host click Start game.
4. To test late join, start the second client after the game starts.

WASD move; mouse look; Space jump; F spawn; E grab/drop;
right mouse throw; X delete held item; C colour; Tab/Escape menu and player list.

Two PCs: run DockCoop.exe directly and enter the host's LAN IP and UDP port7777.
Allow the game through Windows Firewall. Internet IP mode requires port forwarding.

Steam Internet test: start Steam, sign in, run Steam.cmd (Steam.command on Mac).
Host creates a friends-only lobby and displays its ID. Add the accounts as friends,
enter that lobby ID on the other computer and choose Join. No IP or VPN is needed.
A second computer must use a different Steam account and the matching game build.
The host can also open the invitation overlay where Steam overlay is available.
AppID480 is for testing. Two-account Windows/Mac lobby-ID join and gameplay were
manually verified on 3 November 2026; see docs/VERIFICATION.md for scope and gaps.

Rendering is capped at 60 FPS when focused and 30 FPS in the background.
