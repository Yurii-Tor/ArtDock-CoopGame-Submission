DOCK CO-OP - Windows review build

Extract the whole archive. Keep the executable, data directory and DLLs together.

Recommended review: Steam on Windows + Windows or Windows + Mac.
Use two computers and two different Steam accounts added as friends.

1. Steam > Games > Add a Non-Steam Game to My Library > Browse.
   Select DockCoop.exe from this extracted folder.
2. Open its Steam library Properties. Set Launch Options to:
   --transport steam
   Set Start In to this folder containing DockCoop.exe and steam_appid.txt.
3. Enable Steam Overlay in Steam > Settings > In Game. Launch with Play in
   the Steam library and check Shift+Tab. Use the same setup with
   DockCoop.app on Mac; see START-HERE-macOS.txt in its archive.
4. One player chooses Host session; the other stays in the game's main menu.
   Host: Shift+Tab > right-click friend > Invite to Game.
   Guest: accept the invitation. Both names should appear in the lobby.
5. The host clicks Start game. Test the controls below on both computers.
6. Host: Tab/Escape > Kick [player name]. The guest should leave the session
   while the host stays connected. Rejoin to continue other checks.

Invite Steam friends also opens Steam's invitation dialog from inside a lobby.
For invitations, launch from the Steam library. Direct Steam.cmd launch selects
Steam networking but does not guarantee overlay activation.

Alternative: host > Copy lobby ID; guest pastes the numeric ID into
IP address / Steam lobby ID (replace 127.0.0.1), then Join session.
This works without the overlay. The UDP port field is not used in Steam mode.
No VPN, port forwarding or shared LAN is needed. Keep steam_appid.txt (480).

WASD move; mouse look; Space jump; F spawn; E grab/drop;
right mouse throw; X delete held item; C colour; Tab/Escape menu and player list.

Local test on one PC without Steam:
Run Host-Local.cmd and Client-1-Local.cmd (optionally Client-2-Local.cmd),
then Start game on the host. Start another client during gameplay for late join.
For UTP on two PCs on one LAN, run DockCoop.exe directly, use the host's actual
LAN address and UDP port 7777, and allow the game through Windows Firewall.

Manual Windows/Mac coverage includes gameplay, rejoin, graceful disconnect,
Steam friends-menu invitation-to-join and host kick. See README.md,
docs/STEAM.md and docs/VERIFICATION.md for setup, evidence and remaining checks.

Rendering is capped at 60 FPS when focused and 30 FPS in the background.
